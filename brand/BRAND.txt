ReinsCredential brand assets (2026-11-13)

Product name (both locales): ReinsCredential
Do not invent a Chinese product name. Keep the English name in the Dock, About window, and titles.
Tagline EN: Detect which desktop agents access and upload sensitive files

Colors:

- Copper gold: #C9A36A (highlights toward #E8D5A3, shadows toward #8A6A32)
- Key / light text: #F4F0E8
- Cyan accent: #5EEAD4
- Light background: #FAFAF8
- Dark text on light: #0B1220

Files:
- ReinsCredential-AppIcon-1024.png — master 1024×1024 app icon (full-bleed navy square; macOS will apply the squircle)
- ReinsCredential-Logo-rounded-512.png — rounded tile for README and docs
- ReinsCredential-Wordmark-light.png — horizontal lockup on light

Packaging: generate ReinsCredential.icns from the 1024 PNG in build-app.sh (iconutil on macOS). Set CFBundleIconFile / CFBundleIconName. The icon must appear in Dock, Finder, About, and the DMG/zip.
