# Changelog

## 0.2.0

- Evidence-chain closures stay on their own list. The list defaults to the current monitor run, newest first, and the first screen shows zero counts plus an empty-list message even before any closure arrives. Older closures are under History. A TLS handshake is not an upload and is never called not found. An unparsed flight closes once as not visible. Application data after that flight closes as uploaded, with the handshake size and the later body size named separately. A sensitive-file open arms flow tracking in that same pass, and the tree stays watched for three seconds after the file closes. After that grace, kernel flow subscriptions are dropped. Plain HTTP-sized sends still close as uploaded. Each card shows the verdict, app, file, destination, time, and a plain-language basis. The built-in self-check is labeled separately. A limited-coverage state names what was missed. The Dock and reopen bring the main window back on screen with all columns visible. Idle egress does not subscribe to every system flow. Idle process sampling does not re-query every stable process on the 500 ms pass.
- Live detection follows a registered-file open, not a known-agent name list. The owner is the desktop `.app` around that process. Xcode and its `Python.app` are toolchain hops, not the owner, when a desktop app sits further up the parent chain.
- Each actor closes as uploaded, attempted, not found, or not visible. A startup-canary body match does not suppress a later actor on the same file.
- The dashboard exports a JSON evidence chain and a Markdown reading of the same chain. Neither contains raw secret bytes.
- Local builds sign ad-hoc. Developer ID signing and notarization run only when the corresponding environment variables are set.
- Uninstall removes this product's LaunchAgent and app, and keeps evidence unless `--delete-evidence` is passed.
