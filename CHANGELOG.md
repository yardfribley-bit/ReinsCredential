# Changelog

## 0.2.0

- Evidence-chain closures stay on their own list. The list defaults to the current monitor run, newest first, and the first screen shows zero counts plus an empty-list message even before any closure arrives. Older closures are under History. A TLS handshake is not an upload and is never called not found. An unparsed flight closes once as not visible. A kernel counter that still mixes the handshake and the body is not closed as that sum while the file is open. Application data is the upload size, and the handshake size is written beside it. A sensitive-file open is recorded in that same pass, before any kernel subscribe, and still closes if the process exits immediately. The kernel flow socket stays armed for 90 seconds after the last sensitive open, so a later short-lived upload is not dropped while the socket is torn down and opened again. Quitting the app unloads the runtime agent so it is not respawned. Launch and reopen activate the app and order the main window forward on the next turn of the run loop. Plain HTTP-sized sends still close as uploaded. Each card shows the verdict, app, file, destination, time, and a plain-language basis. The built-in self-check is labeled separately. A limited-coverage state names what was missed. The Dock and reopen bring the main window back on screen with all columns visible. Idle egress does not subscribe to every system flow. Idle process sampling does not re-query every stable process on the 500 ms pass.
- A new process is followed for a few seconds, often enough to see a 100 ms file hold that starts just after the previous upload closes. A plain HTTP send is not closed as a TLS handshake. A refused connect that was actually seen stays attempted. The kernel socket drops with the short close grace, and its statistics feed is not drained in a tight loop. Saved split columns taller than the screen, including the comma-separated AppKit form, are discarded and not written back. Discovery does not slow down when the display sleeps or the session locks, and a wake that reveals many processes still checks the newest ones in the same pass. The dashboard redraws only when the evidence files change. Live split columns are not resized by the app, so a cold launch still draws the sidebar, the list, and the inspector.
- The main window keeps its sidebar, list, and detail inside the window. A saved split frame taller than the screen is discarded instead of being restored, and becoming active does not resize the window again.
- Live detection follows a registered-file open, not a known-agent name list. The owner is the desktop `.app` around that process. Xcode and its `Python.app` are toolchain hops, not the owner, when a desktop app sits further up the parent chain.
- Each actor closes as uploaded, attempted, not found, or not visible. A startup-canary body match does not suppress a later actor on the same file.
- The dashboard exports a JSON evidence chain and a Markdown reading of the same chain. Neither contains raw secret bytes.
- Local builds sign ad-hoc. Developer ID signing and notarization run only when the corresponding environment variables are set.
- Uninstall removes this product's LaunchAgent and app, and keeps evidence unless `--delete-evidence` is passed.
